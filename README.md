# الجمهورية الوليدة — محاكاة استراتيجية توثيقية لتاريخ مصر الحديث

هذا **المرحلة الأولى (Phase 1)** من مشروع أكبر بكثير طُلب بمواصفات لعبة استراتيجية
كاملة تغطي مصر من ١٩٥٢ إلى ١٩٧٣ عبر ٨ سيناريوهات. لم يكن ممكنًا بناء المشروع
الكامل بمواصفاته الكاملة (محرك عسكري/اقتصادي/دبلوماسي متكامل × 8 سيناريوهات ×
صور موثقة الحقوق) في تسليم واحد بجودة حقيقية دون أنظمة "شكلية" فارغة من
المحتوى — وهو بالضبط ما طلب البريف الأصلي تجنبه صراحة. لذلك رُكِّز الجهد على
**بناء الأساس المعماري الصحيح + سيناريو ١٩٥٢ الأول كاملًا وشغالًا فعليًا**
بدلاً من هيكل فارغ يغطي كل شيء سطحيًا.

## ما هو منفَّذ فعليًا الآن

- **نماذج بيانات كاملة** (`src/types/index.ts`) لكل الأنظمة المطلوبة: الشخصيات،
  الأحداث، القرارات، العسكري، الاقتصادي، السياسي، الدبلوماسي، الصور التوثيقية
  بميتاداتا كاملة، ومستوى الثقة التاريخية (موثّق / تفسير محتمل / فرع اللاعب).
- **سيناريو ١٩٥٢ كامل** (`src/data/`): ٦ أحداث تاريخية حقيقية موثقة (التعبئة
  الليلية، فجر ٢٣ يوليو، تنازل الملك فاروق، قانون الإصلاح الزراعي، حل
  الأحزاب، إعلان الجمهورية)، كل حدث بمصادره وقراراته وعواقبه.
- **٥ شخصيات تاريخية حقيقية** ببيانات موثقة (محمد نجيب، جمال عبد الناصر،
  عبد الحكيم عامر، الملك فاروق، السفير البريطاني) — وليست شخصيات مختلقة.
- **محرك محاكاة منفصل تمامًا عن الواجهة** (`src/engine/`) قابل للاختبار
  المستقل، يطبّق تأثيرات القرارات على الحالة العامة.
- **واجهة React/TypeScript كاملة** بدعم RTL والعربية، بهوية بصرية مصممة خصيصًا
  ("أرشيف الدولة": بطاقات الأحداث تُعرض كوثائق رسمية مختومة)، بدون أي إيموجي —
  كل الأيقونات SVG مخصصة.
- **أهداف نجاح/فشل قابلة للقياس برمجيًا** لهذا السيناريو تحديدًا.

## ما لم يُنفَّذ بعد (خارطة الطريق الحقيقية)

هذا المشروع يحتاج فريقًا حقيقيًا لإكماله بالجودة المطلوبة. الأولويات بالترتيب:

1. **السيناريوهات ٠٢–٠٨** (١٩٥٤ حتى أكتوبر ١٩٧٣) — نفس النمط المستخدم في
   السيناريو ٠١، بحاجة بحث تاريخي مماثل لكل حدث.
2. **نظام عسكري تكتيكي فعلي** (خرائط، تشكيلات، قتال في الوقت الحقيقي/متوقف) —
   الحالي حاليًا نموذج بيانات ومؤشرات فقط دون واجهة معارك مرئية.
3. **الصور التاريخية الحقيقية**: كل حقول `image` فارغة عمدًا (`assetPath: null`)
   لأن تضمين صور فعلية يتطلب **ترخيصًا قانونيًا حقيقيًا** من الجهة المالكة
   (الأرشيف القومي المصري، مؤسسة الأهرام، Getty، أرشيفات بريطانية/أمريكية
   رسمية...). لم يتم استخدام أي صورة مخزنة أو بديلة حتى لا تُعرض كصورة توثيقية
   زائفة. الحقول جاهزة لاستقبال الصور الحقيقية بمجرد توفير الترخيص.
4. **قاعدة بيانات تاريخية قابلة للتدقيق** (حاليًا الملفات TS ثابتة؛ يمكن
   تطويرها لاحقًا إلى قاعدة بيانات فعلية + واجهة تدقيق للمصادر).
5. **نظام حفظ/تحميل** و**تدويل كامل** (i18n) لو أُريدت لغات إضافية غير العربية.
6. **اختبارات آلية** لمحرك المحاكاة (البنية جاهزة لذلك في `src/engine`).

## التشغيل محليًا

بيئة التطوير الحالية التي بُني بها هذا المشروع **لا تملك اتصالاً بالإنترنت**،
لذلك لم يُشغَّل ولم يُبنَ فعليًا هنا (`npm install` غير ممكن في هذه البيئة).
الكود روجع يدويًا لسلامة الأنواع (TypeScript) لكنه لم يُختبر بتشغيل فعلي.
شغّله عندك بالخطوات التالية:

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite (عادة `http://localhost:5173`).

## بنية المجلدات

```
src/
  types/        # العقد الموحّد لكل بيانات اللعبة
  data/
    characters/ # الشخصيات التاريخية الحقيقية
    events/     # الأحداث التاريخية لكل سيناريو
    scenarios/  # تعريف كل سيناريو (أهداف، حالة ابتدائية)
  engine/       # محرك المحاكاة — منفصل عن React بالكامل
  components/   # واجهة العرض فقط
  styles/       # نظام التصميم (توكنز الألوان والخطوط)
```

## كيف تُضيف سيناريو جديد

1. أنشئ `src/data/characters/19XX.ts` بشخصيات السيناريو الجديدين (إن وجدوا).
2. أنشئ `src/data/events/scenarioNN_19XX.ts` بالأحداث الموثقة مصدرًا مصدرًا.
3. أنشئ `src/data/scenarios/scenarioNN.ts` بنفس نمط `scenario01.ts`.
4. لا تلمس `src/engine/` إلا إذا احتجت تأثيرًا جديدًا غير موجود في `StateEffect`.
